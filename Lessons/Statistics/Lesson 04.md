# Lesson 04: Mode

### What is Mode?
The **Mode** is the value that appears most frequently in a data set.
It is the most common number.

### Types of Mode
- **No Mode:** If no value repeats
- **Unimodal:** One value repeats most (e.g., 2, 3, 3, 4 -> Mode is 3)
- **Bimodal:** Two values repeat equally most
- **Multimodal:** More than two modes

### Example 01
Data: 2, 3, 3, 5, 7
Mode = 3 (because 3 appears twice, others once)

### Example 02
Data: 1, 2, 2, 3, 4, 4, 4
Mode = 4 (appears 3 times)

### Example 03 (No Mode)
Data: 1, 2, 3, 4, 5
No Mode - because all values appear only once.

### Practice Questions
**Q1:** Find the mode: 5, 1, 2, 2, 3, 4
A) 1  B) 2  C) 4
**Correct: B**

**Q2:** Find the mode: 2, 2, 3, 3, 4
A) 2 and 3 (Bimodal)  B) 4  C) No Mode
**Correct: A**

**Q3:** 1,2,3,4 wala Mode eka mokakda?
A) 1  B) No Mode  C) 4
**Correct: B**
